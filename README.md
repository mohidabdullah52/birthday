# Happy Birthday Celebration Web App

An interactive and beautifully animated birthday celebration website built with React and Vite. Inspired by [SelamatUlangTahun](https://github.com/Aghitsniii/SelamatUlangTahun).

## Features

- **Countdown Timer**: Displays an animated countdown to the birthday.
- **Celebration Banner & 3D Confetti**: Festive Happy Birthday banner accompanied by 3D fluttering particle confetti.
- **Handwritten Letter Notes**: Realistic lined notebook paper styling with typewriter text animation and authentic handwriting font (*Handlee*).
- **Interactive Question Card**: Fun playful prompt with an evasive "No!" button that dodges away on hover/click, and a celebratory "Love it!!" button.
- **Heart & Replay**: Beating heart animation, typewriter appreciation message, and easy replay button.
- **Clean & Fast**: Built with React 19, Vite, and optimized CSS.

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/mohidabdullah52/birthday.git

# Navigate into the project folder
cd birthday

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```
